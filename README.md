# John the Ripper Password Cracking Project

## Objective
Demonstrate password cracking using John the Ripper.

## Tools Used
- Kali Linux
- John the Ripper
- rockyou.txt wordlist

## Steps
1. Created hashed password file
2. Used wordlist attack
3. Cracked passwords successfully

## Result
Passwords 123,1234,12345,"secret" were cracked from MD5 hash.

## Learning Outcome
- Learned password hashing
- Understood dictionary attacks
- Practiced cybersecurity tools
